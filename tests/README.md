# Tests

This directory contains all test files for the iLovePDF Python library.

## Structure

```
tests/
├── unit/         # Unit tests for individual modules/classes
├── integration/  # Integration tests for API and workflows
│   └── files_samples/  # Test input files (PDFs, images, etc.) for integration tests
├── README.md     # Overview and navigation for all tests
```

- For details on unit tests, see [unit/README.md](unit/README.md).
- For details on integration tests, see [integration/README.md](integration/README.md).
- Test input files for integration tests are located in `integration/files_samples`.
- For general project information, see [Main README](../README.md).
